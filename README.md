# Volleyball Kingz

Free-to-play pickup volleyball for Los Angeles: find a court, post or join a run, play beach 2v2, 4v4 or indoor 6v6, and keep a rating per format.
Sibling of Basketball Kingz. Draft: not store-ready.

- `docs/SPORT_DESIGN.md` rules, formats, rotation, ratings, courts, avatar, replay, cosmetics
- `docs/DECISIONS.md`, `docs/OPEN_QUESTIONS.md`, `docs/UPSTREAM.md`
- `docs/STATUS.md` what is done, what is not, how to run, real test results
